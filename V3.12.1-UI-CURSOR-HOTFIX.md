# Version 3.12.1: ImGui/UI cursor hotfix

This cursor-only hotfix enables ImGui's software cursor whenever the plugin menu is open.

Changes:
- `io.MouseDrawCursor` now follows plugin-menu visibility instead of being forced off.
- The native Win32 cursor is hidden while the plugin menu owns mouse input.
- The visible cursor and ImGui hover/click testing use the same `io.MousePos`, eliminating the visible above-left offset between the pointer and selected control.
- Closing the plugin menu disables the ImGui software cursor again.

No media/audio code was changed.
