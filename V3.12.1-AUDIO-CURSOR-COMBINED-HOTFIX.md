# 3.12.1 combined audio + cursor hotfix

Applied on top of the supplied **3.12.1 cursor-alignment-hotfix** source without replacing the newer 3.11/3.12 traffic-radio code.

## Cursor
- ImGui now draws the plugin-menu cursor, so the visible pointer and ImGui hit-testing use the same coordinate space.
- The Win32 client-area cursor is hidden while the plugin menu owns mouse input.
- Each frame refreshes ImGui mouse position from `GetCursorPos` + `ScreenToClient` immediately before `ImGui::NewFrame()`.
- Existing 3.12.1 DirectInput filtering (X/Y only, buttons/wheel blocked) is preserved.

## Audio
- Adds WebView2 unmuted autoplay policy.
- Removes the unsafe `media.crossOrigin` shortcut before `createMediaElementSource()`; the app-owned `traffic.prism.local` virtual host remains allowed.
- Tracks intentional mute state and explicitly unmutes YouTube/direct playback on startup when the user has not muted it.
- Uses Windows session master volume for overall gain/ducking and channel volume only for stereo pan when both interfaces are available.
- Logs baseline WebView audio-session master/mute/channel state.
- Initializes Native Direct Media as unmuted at 100% volume.
