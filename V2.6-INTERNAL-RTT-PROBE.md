# PrismTextureStreamerFB 2.6 Internal RTT Probe

## Purpose

This is the safe diagnostic stage of the true in-game reverse-camera work.
Static analysis of the supplied ETS2 1.60.1.7 executable found the game's nine
internal camera slots:

`close`, `close_s`, `far`, `far_s`, `side`, `front`, `hood`, `park`, and
`park_360`.

The plugin now recognizes that exact executable, observes the internal camera
scheduler, and can record the D3D11 render targets used during a short trace.
It does not yet create or move an internal camera. The driver's camera is never
changed by this diagnostic build.

## Safety guard

The internal hook is enabled only when all of these values match:

- ETS2 executable timestamp: `0x6A426DE5`
- Loaded image size: `0x0382D000`
- Internal camera-scheduler signature: exactly one match
- Scheduler RVA: `0x00524DB0`

If any value differs, the internal hook stays disabled and the rest of the
multimedia plugin continues normally.

## Run the 10-second test

1. Install the complete 2.6 package and start ETS2 in DirectX 11 mode.
2. Load a truck into gameplay.
3. Open the plugin with **Ctrl+F8**.
4. Open the target screen, then **Automatic Reverse Camera**.
5. Open **Internal render-to-texture probe**.
6. Confirm these two lines are green/ready:
   - **Exact ETS2 1.60.1.7 build recognized**
   - **D3D11 render-target observer: ready**
7. Select reverse gear.
8. Click **Start 10-second RTT trace**.
9. Close the plugin menu and steer or move slowly while remaining in reverse.
10. Wait at least 10 seconds, then reopen the probe. It should show a candidate
    count and a short ranked list.
11. Exit the game normally.
12. Send back:
    `Documents\Euro Truck Simulator 2\game.log.txt`

Do not send the executable again unless the game updates.
No centre mirror or F2 virtual mirror is required for this probe.

## Performance

- Outside a trace, the D3D11 observer performs one disabled atomic check per
  render-target binding.
- The internal scheduler hook records its slot list once, then passes through.
- During the 10-second trace only, the plugin reads bound render-target
  descriptions and records counters. A temporary performance drop during the
  trace is expected.
- No frame pixels are copied or read back by this probe.

## What happens after the trace

The trace identifies whether ETS2 creates a usable `park` or `park_360`
render texture on this truck and which D3D11 resource carries it. The next
stage will use that result to:

1. create or activate a dedicated rear camera without changing the driver view;
2. place it from the final trailer transform supplied by SPF;
3. feed the resulting GPU texture into the selected GPS/dashboard screen; and
4. expose Economy, Balanced, Quality, and Ultra reverse-render profiles.

The existing calibrated window-capture reverse source remains available as a
legacy fallback until the internal path is validated.
