# PrismTextureStreamerFB 3.2 Media Library

- Keeps separate saved-link lists for YouTube and Spotify in each configured
  game screen.
- Switches services and saved links directly from the ImGui plugin menu.
- Adds, updates, and removes links without editing the configuration file.
- Migrates the existing single `MediaUrl` into the appropriate list.
- Extends the outside-truck low-pass cutoff control down from 120 Hz to 20 Hz
  for stronger distance muffling without changing video capture framerate.
- Starts the media helper without activating or focusing its window.
- Associates the helper with the current ETS2/ATS process and closes it when
  the game exits.
