OPTIONAL SPF CAMERA BRIDGE — VERSION 4.0.0

The bridge improves adaptive audio by publishing exact camera, truck, and
trailer placement. It does not provide a reverse camera and does not enumerate
AI traffic.

1. Install the SCS Plugin Framework (SPF) for ETS2/ATS.
2. Copy the packaged PrismCameraBridge folder into SPF's plugin folder.
3. Start the game. The main plugin automatically uses the shared camera feed
   when it is available and falls back safely when it is absent.

The bridge is optional. YouTube, Spotify Web, display streaming, hotkeys, and
normal adaptive cabin/exterior audio work without it.
