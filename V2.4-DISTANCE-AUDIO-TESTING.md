# PrismTextureStreamerFB 2.4 Distance Audio Test

## Installation

1. Install the complete normal plugin package.
2. For exact distance, follow `SPF-OPTIONAL/SPF-BRIDGE-INSTALL.txt`.
3. Use **Integrated Media Client** and enable **Adaptive Cabin Audio**.
4. Switch to interior camera `1` once to calibrate the driver-head anchor.

The main plugin still works without SPF; it then uses fixed outside volume.

## Exact camera distance

1. Start a video and leave the truck engine running.
2. Switch to an outside camera.
3. Confirm the menu shows **Camera distance from driver**.
4. Move the camera closer and farther from the cab.
5. Confirm the displayed metres update even while the truck is moving.
6. Switch to camera `1`, change trucks, then switch outside once more. This
   recalibrates the driver position for the new truck.

## Distance volume

Start with:

- Full-volume distance: `1.5 m`
- Mute/minimum-volume distance: `20 m`
- Minimum volume when far away: `0.00`

At or below the full-volume distance, media should remain at normal volume.
It should fade smoothly between the two distances and reach silence at the
far distance. Set minimum volume above zero if complete silence is unwanted.

## Low-pass filter

1. Enable **Distance low-pass (muffle far audio)**.
2. Set **Far-distance cutoff** to `650 Hz`.
3. Move the outside camera away from the cab.
4. Confirm high frequencies progressively disappear with distance.
5. Return to the cab; normal bandwidth should return immediately.
6. Disable the option; distance volume should continue without muffling.

The filter runs only inside the Integrated Media Client documents, including
the YouTube frame. It does not filter the game's engine, traffic, navigation,
or radio audio session. If WebView2 blocks creation of a running audio graph,
or a direct media server does not permit safe audio routing, the controller
leaves the original media audio route untouched.

## Performance

- The SPF companion only reads two camera values and updates a small shared
  memory record once per frame; it performs no capture or rendering.
- Distance math is a few scalar operations per telemetry tick.
- The low-pass is a browser audio-node operation and does not add another
  video capture, texture upload, or game render pass.
