# Prism rear-camera kit test

This build replaces the cloned mirror placement with a guarded, adjustable
rear-camera mount. It runs only on the exact ETS2 1.60.1.7 executable already
recognized by the internal render probe.

## Install

1. Install the root plugin package as before.
2. Replace the old SPF companion with the new
   `SPF-OPTIONAL/PrismCameraBridge/PrismCameraBridge.dll`. The new bridge is
   required because it publishes both truck and final-trailer placement.
3. Install the optional accessory mod source after exporting its small model
   with SCS Blender Tools, or leave the cosmetic accessory out during testing.
4. In the plugin menu select **Internal park camera**, enable
   **Camera kit installed on this vehicle**, then enable Preview.

## Calibration

- Start with yaw `180`, pitch `-8`, lateral `0`, height `2.6`, and
  forward/rear `-0.35`.
- If the view faces forward, set yaw to `0`.
- Adjust pitch in small steps. A positive/negative direction can differ with
  the camera definition used by the current truck.
- With a connected trailer, **Follow final connected trailer** uses SPF's last
  connected trailer pose. Without it, the camera uses the truck mirror clone
  as a safe local anchor.

## Performance

- Economy: 10 FPS, lowest reversing cost.
- Balanced: 15 FPS, recommended.
- Quality: 20 FPS.
- Ultra: 30 FPS, highest reversing cost.

Forward driving still does not schedule the dormant park render when
zero-forward-impact is enabled.

This is a guarded test build. If the image is misplaced, use the calibration
controls rather than editing memory offsets. If a newer ETS2 executable is
detected, the internal mode refuses to activate.
