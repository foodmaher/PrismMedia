# Spotify Embed test

The Integrated Media Client now recognizes official Spotify URLs for:

- playlists;
- albums;
- tracks;
- artists;
- podcasts/shows;
- podcast episodes.

Paste a normal Spotify share URL or an `open.spotify.com/embed/...` URL into
the existing media URL field and select **Start / Reload**.

Play, Pause, Play/Pause, truck-engine pause/resume, screen brightness and the
existing process-level adaptive audio path are supported. Spotify's public
iFrame API does not expose Next, Previous-track, Mute or Volume methods.
Previous restarts the current item; unsupported controls display a short
message and Spotify's own on-screen controls remain available.

Spotify may require the user to press Play once because browser autoplay
policies are controlled by Spotify and WebView2. Playback availability and
track length are also controlled by Spotify Embed and the user's account.
