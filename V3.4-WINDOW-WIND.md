# Version 3.4: open-window wind and cleaner installation

## Installation layout

Copy the two runtime items into `bin\win_x64\plugins`:

```text
plugins\
  PrismTextureStreamerFB.dll
  PrismTextureStreamerFB\
    PrismMediaClient.exe
    PrismMediaClient.exe.config
    Microsoft.Web.WebView2.*
    www\
    docs\
    SPF-OPTIONAL\
```

The main DLL must stay directly in `plugins` because that is where ETS2/ATS
loads telemetry plugins. The media client and its dependencies now live in one
clearly named subfolder. Older flat installations remain compatible, but their
old helper files can be removed after the new folder has been copied.

## Open-window wind audio

Open **Ctrl+F8 > Open-Window Wind Audio**, enable the feature, then bind the
four controls to the exact same left/right window open/close keys configured in
ETS2/ATS. The SCS telemetry API supplies truck speed but does not expose the
animated window position, so the plugin follows those held keys using the
configured full-travel time. Manual left/right synchronization sliders recover
from a missed key or a changed truck.

The sound:

- plays only while driving in an interior camera;
- scales smoothly with absolute truck speed and window opening;
- pans toward the open side;
- stops when the windows close, the truck stops, the player leaves the cab, or
  the feature is disabled; and
- runs in the existing media helper, not on the game render thread.

When wind is the only enabled helper feature, the client starts in audio-only
mode and does not initialize WebView2. If a YouTube or Spotify screen is added
later, the same helper initializes its media surface on demand.

The recommended generated source is synthesized locally once in
`%LOCALAPPDATA%\PrismTextureStreamerFB`, so no large audio asset is included in
the package. A seamless WAV, MP3, WMA, M4A or AAC loop can be selected instead.
If a custom file is missing or unsupported, the generated source is used.

## Recommended setup

- Generated natural wind
- Maximum volume: 60-70%
- Start: 5-10 km/h
- Full volume: 90-110 km/h
- Window travel: match the truck animation, usually around 3 seconds

For the most believable result, keep this effect below engine and tyre volume.
Use a seamless, steady wind loop without voices, horns, or road noise when
selecting a custom file.
