# Version 3.9 Spotify session, live capture and configuration backups

Version: `3.9.0-session-backup-menu`

## Spotify Full Web Player fixes

- The helper now creates its WebView2 environment only once. This removes the
  `already initialized with a different CoreWebView2Environment` failure seen
  in the supplied client log.
- Spotify cookies are checkpointed to
  `%LOCALAPPDATA%\PrismTextureStreamerFB\SpotifySession.dat` after successful
  Spotify navigation and before the interactive helper returns to silent mode.
  The checkpoint is encrypted for the current Windows user with DPAPI and is
  restored before the first navigation after the next game start.
- **Clear Spotify login/session** removes both WebView2 browsing data and the
  encrypted checkpoint.
- Chromium background and native-occlusion throttling are disabled only for
  the media helper. This keeps the Full Web Player compositor updating while
  its silent window is behind the game, preventing the GPS from remaining on
  the first captured image.
- Diagnostic navigation URLs omit query strings so login hints, flow tokens
  and other private query data are no longer written to the client log.

The Full Web Player remains heavier than Spotify Embed. Embed is still the
recommended performance option when account login and full Spotify controls
are not needed.

## Three rolling configuration restore points

The active configuration remains:

`%LOCALAPPDATA%\PrismTextureStreamerFB\config.ini`

The previous three distinct saved configurations are maintained separately as
`config.ini.backup1.ini`, `config.ini.backup2.ini`, and
`config.ini.backup3.ini`. New saves move the former active configuration into
backup 1, shift older restore points down, and discard only the oldest slot.
An unchanged automatic shutdown save does not create a duplicate restore
point.

Open **Configuration Backups** in the plugin menu to save immediately or
restore any available timestamped slot. Restoring preserves the configuration
that was active immediately before the restore as the newest backup. Deleting
only `config.ini` does not delete the three backup files.

## Gamepad menu toggle

Enable **Gamepad controls** under **Media Hotkeys**, then edit the new
**Plugin menu** combination. The default is `LB + Start/Menu`. `Start/Menu`
and `Back/View` are now available as assignable inputs. The chord is checked
while the overlay is closed and uses the same XInput-first, Windows-joystick
fallback path as the media commands.

Steam Input can hide the physical controller from both in-process APIs. If
the plugin log says no controller is connected, disable Steam Input for the
game as described in the version 3.8 notes.

## Verification checklist

1. Select Spotify **Full Web Player**, open its login window, sign in, and
   choose **Return helper to silent mode**.
2. Confirm the GPS continues changing during gameplay, then close and restart
   the game and confirm Spotify remains signed in.
3. Make and save three visibly different settings changes. Open
   **Configuration Backups** and restore each timestamped state.
4. With gamepad controls enabled, press `LB + Start/Menu` once to open the
   overlay and once again to close it.
