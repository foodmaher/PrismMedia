# 3.11.11 source-path park capture

The engine can copy several camera views into the same 256x256 RGBA16F
destination. Selecting that destination therefore allowed enlarged mirrors or
the player camera to overwrite the park image before the Present-time readback.

This version treats A-D as individual source-to-destination copy paths. The
selected path is copied immediately into the existing non-blocking staging
ring from inside the intercepted game copy. Later writes to the shared engine
destination cannot alter that snapshot.

Copy paths that stop updating for at least one second can be recycled when the
game recreates its camera resources after an interior/exterior camera change.
Auto selects the first observed path; A-D remain available to identify the park
path for a particular truck and camera configuration.

The media client, web helper, audio implementation, and DirectInput cursor
proxy are unchanged from the working 3.11.10 source.
