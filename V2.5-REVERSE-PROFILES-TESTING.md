# PrismTextureStreamerFB 2.5 Reverse Profile Test

## Install and enable SPF

1. Install the normal package.
2. Copy `SPF-OPTIONAL/PrismCameraBridge` into
   `bin/win_x64/plugins/spfPlugins`.
3. Start the game, press **Delete**, open **Plugins**, and enable
   **PrismCameraBridge**.
4. Fully restart the game.

## Test the working reverse feed

1. Use interior camera 1.
2. Press **F2** until the required left or right virtual side mirror appears.
3. Open **Automatic Reverse Camera** on the target screen.
4. Enable **Show reverse view on this screen** and
   **Preview / calibrate now**.
5. Move and resize the capture rectangle until it contains only that mirror.
6. Disable preview, select reverse, and confirm the source starts.
7. Select a forward gear and confirm the capture closes when
   **Zero forward impact** is enabled.

## Compare the profiles

Test Economy, Balanced, Quality, and Ultra while watching the plugin's
performance monitor. Confirm that each selection changes the displayed
capture resolution and FPS, is saved, and survives a full game restart.

Balanced is the recommended starting point. Economy is intended for maximum
headroom; Ultra should be used only when GPU and CPU headroom are available.

## Verify trailer tracking

1. Enable `PrismCameraBridge` in SPF.
2. Attach one trailer and check for **Tail trailer anchor ready (1 trailer)**.
3. Attach a multiple-trailer combination and verify the displayed count.
4. Detach the trailer and verify the menu reports that the truck anchor would
   be used.

This is transform tracking, not yet a centred camera image. SPF 1.2 can move
the active/free camera but does not provide a second render-to-texture camera.
The plugin therefore keeps the virtual-mirror feed instead of changing or
flickering the player's main driving view.
