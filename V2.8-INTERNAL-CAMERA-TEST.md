# PrismTextureStreamerFB 2.8 Internal Camera Test

## What this build changes

This is the first build that displays ETS2's independent slot 7 park-camera
render target on the selected GPS. It does not capture the game window and
does not move the player's main camera.

The internal path is guarded to the exact ETS2 `1.60.1.7` executable already
validated by version 2.7. ATS and any different ETS2 executable retain the
stable window-crop method.

## Installation

1. Download and extract the complete
   `PrismTextureStreamerFB-2.8.0-internal-camera-test` Actions artifact.
2. Close ETS2.
3. Replace the previous plugin package in:

   `<ETS2>\bin\win_x64\plugins`

4. Keep `PrismTextureStreamerFB.dll`, `PrismMediaClient.exe`, its dependency
   DLLs and the `www` folder together.

## First test

1. Start ETS2 and open the plugin menu with **Ctrl+F8**.
2. On the GPS screen, enable **Show reverse view on this screen**.
3. Select **Internal park camera (GPU, experimental)**.
4. Choose **Balanced (15 FPS)**.
5. Close the plugin menu and wait three seconds for the configuration to save.
6. Reload the truck once, or restart ETS2.
7. Open the menu and confirm:

   - `Internal slot 7: installed`
   - `resource: ready`
   - `colour target: ready`
   - `GPU target: 256x256 DXGI`

8. Enable **Preview / calibrate now**.

The rear image should replace the normal media on the GPS. Disable Preview to
confirm that the normal video returns immediately. Then select reverse gear
and confirm automatic switching.

## Display controls

- Use **Flip Screen** if the park image is vertically inverted.
- Use the normal scaling control:
  - **Crop** fills a wide GPS and trims the top and bottom of the square camera.
  - **Fit** keeps the whole square image with black side bars.
  - **Stretch** fills the GPS but changes the image proportions.
- Screen Brightness and Edge Colour-Bleed Guard also apply to the internal
  camera through the GPU shader.

## Performance profiles

| Profile | Internal render rate | Expected impact |
|---|---:|---|
| Economy | 10 FPS | Very low |
| Balanced | 15 FPS | Low; recommended |
| Quality | 20 FPS | Medium |
| Ultra | 30 FPS | Higher |

Slot 7 is not scheduled while driving forward, so the additional camera
render cost is zero outside reverse and Preview. The GPU compositor also stops
updating, leaving the restored media texture in place.

## Expected log messages

```text
[RTT park] Internal park resource: created (descriptor 256x256).
[RTT park] Captured park colour target: 256x256 DXGI(26), score=500.
[RTT park] GPU compositor initialized.
```

If `colour target` remains `waiting`, reload the truck once and send
`game.log.txt`. If the GPS shows the wrong camera, a black image or corrupted
colours, disable Preview, switch back to **Window crop (stable)**, and send a
screenshot plus `game.log.txt`.
