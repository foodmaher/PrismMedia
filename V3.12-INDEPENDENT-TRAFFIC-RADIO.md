# Version 3.12: independent AI traffic audio

This release separates positional AI traffic audio from the dashboard Spotify
Full Web Player. Spotify permits only one active playback session in this
design, so opening another Spotify website for an AI car could stop the main
music. The traffic helper now accepts only independent audio sources and never
navigates to Spotify or YouTube.

## Supported sources

- A local audio file path, such as `C:\Music\road-mix.mp3`
- A `file:///` URL to a local audio file
- A direct HTTP/HTTPS audio or stream URL that WebView2 can play

A normal Spotify or YouTube page URL is not a direct audio source and is
rejected. The plugin does not extract media, bypass a service player, download
tracks, or create temporary clips. A remote host must serve playable audio;
browser codec and server access/CORS rules still apply. Remote sources without
CORS permission can still be browser-playable, but Web Audio may be unable to
apply the low-pass filter; use a CORS-enabled direct URL when filtering is
required. Local files use the helper's trusted virtual host and retain the
filter.

## Selection and playback

- The stable hash of an audible AI ID chooses one entry from the source list.
- When duration is known and seekable, the same hash chooses a starting point
  on a 60-second grid. Playback continues normally past the next minute and to
  the end of the media; one minute is only the offset spacing.
- Live or non-seekable streams play continuously without a forced seek.
- The helper pauses when no eligible AI is in range and resumes automatically
  when one returns. Starting dashboard music does not require disabling and
  re-enabling traffic audio.
- Only the nearest selected AI is decoded. The existing four-metre handoff
  margin avoids rapid reloads in dense traffic.

Distance falloff, stereo direction and the configurable near/far low-pass
filter continue to use the listener and AI positions supplied by the SPF
companion.

## Setup

1. Install and enable the optional SPF companion as described in
   `SPF-BRIDGE-INSTALL.txt`.
2. Open a screen's **AI Traffic Radios (SPF)** panel.
3. Enter a local file path or direct audio/stream URL and choose
   **Add traffic source**. Repeat for additional sources.
4. Enable positional AI traffic music and tune density, volume, distances and
   cutoff values.

The dashboard screen does not need to use Integrated Media, and its Spotify
selection is not reused by traffic audio.
