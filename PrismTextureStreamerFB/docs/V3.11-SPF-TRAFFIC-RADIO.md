# Version 3.11: SPF AI traffic radio

> Playback setup in this document describes the original 3.11 design. Version
> 3.12 keeps the SPF positioning model but replaces the second Spotify/YouTube
> client with independent local files and direct audio URLs. See
> `V3.12-INDEPENDENT-TRAFFIC-RADIO.md`.

The optional `PrismCameraBridge` now enumerates SPF's live traffic handles and
publishes the 32 actors nearest the player's truck. Each handle is used only in
the frame in which SPF returned it. The bridge reads Prism3D's 1.60
`traffic_actor_t::placement` at `+0x28`, converts its local X/Z with the signed
512-metre sector coordinates, and rejects non-finite or implausible data. A
despawn during the copy is caught without taking down the game.

## Playback model

- Vehicle selection is a stable hash of the traffic ID. The default density is
  50%, so an actor does not repeatedly switch between radio/no-radio states.
- Only the nearest selected actor inside the configured mute distance is
  decoded. A four-metre handoff margin prevents rapid switching in dense
  traffic.
- A separate silent `PrismMediaClient` process and WebView profile isolate the
  traffic radio from the truck-screen player and from ETS2/ATS game audio.
- Distance controls gain and logarithmically blends the near/far low-pass
  cutoffs. Relative actor direction controls stereo pan.
- The original 3.11 helper reused the dashboard media source. This was replaced
  in 3.12 because a second Spotify website competes for the same account
  playback session.

The helper is launched and controlled from a below-normal worker thread. The
game telemetry callback only copies a small desired state; process startup and
WebView messaging never block the game thread. Disabling the option or shutting
down the telemetry plugin closes the dedicated helper.

## Setup

1. Install and enable the packaged SPF companion using
   `SPF-BRIDGE-INSTALL.txt`, then restart the game.
2. Open **AI Traffic Radios (SPF)** and add one or more local audio files or
   direct audio/stream URLs.
3. Enable positional AI traffic music.
4. Tune vehicle percentage, maximum volume, audible range and near/far cutoff.

Spotify and YouTube page URLs are intentionally rejected for AI traffic. The
dashboard Spotify player remains the only Spotify client.

If the V4 bridge feed is missing, stale, disabled, or has no valid traffic
actors, the traffic helper is not started and the feature remains silent.
