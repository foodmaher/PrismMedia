# PrismTextureStreamerFB 2.3 Adaptive Feature Test

## Before starting

- Use ETS2 or ATS in DX11 windowed or borderless mode.
- Install the full 2.3 artifact, including the updated
  `PrismMediaClient.exe`.
- Press F2 until the game's fixed virtual mirror is visible.
- Open the plugin menu with Ctrl+F8.

## Adaptive cabin audio

1. Start a video with Integrated Media Client.
2. Open **Adaptive Cabin Audio**.
3. Enable head-position adaptive sound.
4. Set Spatial strength to `1.00` temporarily so the effect is obvious.
5. Look right. The dashboard media should move toward the left ear.
6. Look left. It should move toward the right ear.
7. Look fully away. Volume should approach **Volume facing away**.
8. Move to an outside camera. Volume should approach
   **Volume when outside**, and the menu should report **external camera**
   instead of showing an old head distance.
9. Open the pause/menu UI. Volume should change to
   **Volume in menus / before driving** (default `50%`).
10. Return to the interior camera. Live head distance and heading should resume.
11. Disable adaptive sound. Normal centred media sound should return.
12. Confirm engine, traffic, navigation, and other game sounds did not move.

If left/right feels reversed for a particular camera mod, set Speaker direction
to the opposite side and report the live heading shown in the menu.

## Screen brightness

1. Set **Screen Brightness** to `50%`; the GPS/dashboard video should darken.
2. Set it to `150%`; the video should brighten without changing the game scene.
3. Set it back to `100%`; colours should match the source and the fast copy
   path should be restored.
4. Pause capture, change brightness, and confirm the cached frame updates.
5. Restart the game and confirm brightness is restored for that screen.

## Engine-powered playback

1. Enable **Play media only while truck engine is running**.
2. Remain in gameplay and stop the truck engine. Video and sound should pause.
3. Start the engine. Playback should resume from the same position.
4. Manually pause the video, cycle the engine off and on, and confirm it stays
   manually paused.
5. Open a game menu. Engine control should report inactive and the configured
   menu/startup volume should apply.

## GPS edge-colour fix

1. Use Stretch or Crop so the video fills the complete GPS texture.
2. Set **Edge Colour-Bleed Guard** to `0 px` and look for colour tint around
   the truck's GPS bezel.
3. Set the guard to `2 px`. The coloured halo should disappear without a thick
   decorative border.
4. Increase it only if a specific truck material still samples the video edge.

## Automatic reverse mirror

1. Expand **Automatic Reverse Mirror** on the target screen.
2. Enable **Show reverse view on this screen**.
3. Keep **Zero forward impact** enabled.
4. Enable **Preview / calibrate now**.
5. Move the ImGui window away from the virtual mirror if it overlaps.
6. Adjust Mirror left/top/width/height until only the virtual mirror appears.
7. Disable preview.
8. Select a forward gear. The menu should say capture is closed.
9. Select reverse. The mirror should appear after a short startup moment.
10. Return to forward gear. The normal media source should return and reverse
    capture should close.
11. Repeat with a trailer attached and turn sharply while reversing. The game
    mirror should continue to handle the articulated view.

## Performance check

- Compare forward FPS with reverse mode disabled and with reverse mode enabled
  plus **Zero forward impact**. Measured plugin work should be effectively the
  same because the reverse capture object is closed.
- In reverse, start at 20 FPS. Lower it to 15 if desired.
- Keep the crop tight: GPU readback is limited to the cropped mirror rectangle,
  so a smaller crop transfers fewer pixels.

## Known boundaries

- This is a reverse mirror, not an undocumented extra scene camera mounted at
  the trailer tail.
- The fixed virtual mirror must be enabled and visible in the game.
- Exclusive fullscreen or capture-blocking overlays can prevent same-window
  Windows Graphics Capture. Use borderless mode if startup fails.
- Adaptive stereo audio is intentionally limited to Integrated Media Client.
  Native Direct Media shares the game process audio path and is left untouched.
