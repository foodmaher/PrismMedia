# Version 3.10 visual, audio and input reliability

Version: `3.10.1-engine-standby-logo`

## Brightness restoration and automatic lighting

The media helper now retains the requested brightness independently from the
current webpage. It reapplies the same value after every YouTube, Spotify, or
local-player navigation, including the final Full Spotify Web navigation after
a game restart. This fixes the same saved brightness producing a brighter GPS
until its slider was moved again.

Each screen also has an optional **Automatic brightness from game lighting**
mode. When enabled, the plugin samples a 4 x 4 grid from the game backbuffer at
most four times per second before the plugin UI is drawn. Two staging slots and
GPU completion queries make the readback non-blocking. The sampler is dormant
when no screen enables the feature. The saved manual brightness remains the
baseline, with separate dark-scene and bright-scene multipliers.

When engine-follow playback is enabled, the stopped engine replaces media with
a dark standby card showing the current truck's localized brand and model name
from SCS truck-configuration telemetry. **Engine-off logo brightness** controls
that generated card. The logo is rebuilt only when the truck or target texture
size changes; it does not need an image file or a live capture. Starting the
engine restores the cached media immediately and then resumes live playback.

## Cursor and keyboard fixes

The plugin now uses the Win32 cursor instead of also drawing an ImGui software
cursor. Version 3.12.1 additionally keeps the game's menu cursor aligned by
passing X/Y movement and hides the redundant Win32 cursor image in menus while
still filtering buttons and wheel input. The
old `LB + Start/Menu` default is migrated to
`LB + Right Stick Click`, because ETS2/ATS also consumes Start/Menu and can
enable its own cursor. A warning remains visible if Start/Menu is selected
manually.

Keyboard media controls now use the current key-down bit plus plugin-owned edge
detection. The old shared transition bit could be consumed by the game before
the plugin read it, which made one keyboard press appear to require several
attempts. Volume keys support the same intentional hold-to-repeat timing as the
gamepad bindings.

## Audio controls

- **Interior-cab master volume** reduces media only in the interior camera.
  Exterior near/far volume, distance attenuation, and low-pass controls remain
  independent.
- Volume Up and Volume Down adjust the WebView Windows audio session directly
  in 5% steps. This works for YouTube and Spotify Full Web even when a protected
  player or framework-owned webpage slider rejects scripted changes. The old
  Spotify Embed path was removed in version 3.11.1.
- WebView master volume remains multiplicative with adaptive gain,
  environment-aware ducking, and stereo pan.

## Diagnostics

The ten-second runtime summary includes sampled game luminance and validity.
Truck-configuration and standby-logo changes are also logged.
The helper logs brightness restoration after navigation and rate-limited live
brightness changes. WebView master-volume changes are logged with their new
percentage.
