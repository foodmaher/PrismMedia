# 3.11.14 custom-camera call-chain diagnostic

The second trace proved the active slot command reaches RVA `0x00722020`
through an indirect call path. The earlier direct caller is valid code but is
not the runtime path used by this truck/render configuration.

This build preserves the time-spaced command sampling and adds:

- the runtime call stack, with executable addresses converted to RVAs;
- a bounded read of the per-command owner referenced at command offset `+F8`;
- the existing command and stable render-context records.

No additional Prism3D render is submitted. One ordinary 20-second trace is
enough; camera-mode cycling is optional because the call-chain is the primary
target of this run.
