# Version 3.6 telemetry environment ducking

This release removes the plugin's external stationary, city, highway and wind
audio players. ETS2/ATS now remains the only source of environment sound.

## How it works

The plugin reads official SCS telemetry for truck speed and each truck wheel's
ground-contact state. A smooth estimator combines aerodynamic and road-noise
curves into a live environment intensity from 0 to 100 percent. The result only
changes Integrated Media Client volume; it does not capture, replace or process
the game's audio.

The estimator updates with telemetry while driving and returns media to its
normal volume in menus or when telemetry pauses. Wheel contact keeps the road
component responsive when wheels leave or regain the ground.

## Settings

Open `Environment-Aware Media Volume` in the ImGui menu:

- `Enable environment-aware media reduction` turns the feature on or off.
- `Interior media reduction` sets the maximum reduction in a cab camera.
- `Exterior media reduction` sets the maximum reduction in an outside camera.

The live row shows truck speed, grounded-wheel ratio, estimated environment
intensity, detected camera mode and resulting media volume. Settings are saved
in `%LOCALAPPDATA%\PrismTextureStreamerFB\config.ini`.

## Performance

The estimator performs a few arithmetic operations per telemetry tick and
updates the existing media audio-session controller at no more than 20 Hz using
a non-blocking private window message. It starts no additional process, thread,
decoder, audio loop, capture session or render pass.
