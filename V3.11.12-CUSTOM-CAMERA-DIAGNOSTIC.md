# 3.11.12 custom-camera diagnostic

This is a read-only discovery build for ETS2 PE timestamp `0x6A426DE5` and
image size `0x0382D000`. It does not submit a second scene render.

The build hooks the verified mirror worker at RVA `0x0046CB80` and correlates
its four live arguments with the already verified slot dispatcher at RVA
`0x00722020`. During a normal render-target trace, up to sixteen unique slot-7
states are written as `[RTT custom]` records. Each record contains bounded
copies of the command, camera input, request and render-context structures.
All reads use structured exception handling and an unreadable object is logged
instead of being dereferenced further.

## One-pass test

Start a 20-30 second render diagnostic, reverse with the interior view active,
show the left enlarged mirror, show the right enlarged mirror, switch to an
external camera, and return to the interior before the trace ends. Provide the
resulting `game.log.txt`. This covers the state transitions needed to locate
the scene submission, camera transform, target ownership and visibility mask.
