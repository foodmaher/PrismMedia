# 3.11.13 custom-camera state diagnostic

The first trace proved the slot dispatcher runs after the high-level worker
state has crossed a thread boundary. This diagnostic captures the four worker
arguments directly at RVA `0x0046CB80` every two seconds and captures a slot-7
command every second. Sampling is time-spaced so ordinary vehicle movement
does not consume all records before camera-mode transitions occur.

Run the same 20-second trace: reverse in the interior, show both enlarged
mirrors, switch outside, then return inside. The log should contain both
`[RTT custom worker]` and `[RTT custom] snapshot=` records.
