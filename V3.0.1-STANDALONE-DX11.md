# Standalone DirectX 11 test

ReShade is not required by this build.

Previous builds discovered the DirectX 11 swap-chain functions by creating a
temporary swap chain against `GetForegroundWindow()`. During telemetry-plugin
startup that window can be absent or unsuitable. On affected systems the
Present hook never ran, so ImGui was unavailable and the replacement GPS
texture remained black. ReShade happened to hide the timing problem.

This build:

- creates a private hidden 8x8 Win32 probe window;
- creates the temporary DirectX 11 swap chain against that valid window;
- checks creation and enable results for Present, ResizeBuffers, and
  CreateTexture2D hooks;
- logs the exact failed stage and status;
- aborts before applying Prism screen overrides when DX11 setup fails.

## Test without ReShade

1. Back up the current working installation.
2. Remove or temporarily rename ReShade's `dxgi.dll` from
   `bin\win_x64`.
3. Keep `PrismTextureStreamerFB.dll` and the media-client files in
   `bin\win_x64\plugins`.
4. Start ETS2 in DirectX 11 mode.
5. Press Ctrl+F8. Confirm that ImGui opens and then test the GPS.

The expected `game.log.txt` line is:

`[dx11::present] Standalone DX11 hooks installed using private probe window.`

If it fails, send `game.log.txt`; the new log identifies whether window,
swap-chain, Present, ResizeBuffers, or texture-hook setup failed.
